# Public version validation

Validation date: 2026-10-22. Checks use synthetic inputs and the existing
independent research image. No live trading service was started or restarted,
no dependencies were installed in the private environment, and no real trades
database was used for validation.

## Strategy integrity and loading

`user_data/strategies/my_strategy.py` is a byte-for-byte copy of the source
strategy, including all signals, risk parameters, order settings and leverage
rules. SHA256:

```text
e9651deadb2d42b363cd9a7f528db84a29d220c671324a9f51fdbb2e1d3b4672
```

`scripts/validate_strategy.py` successfully loaded `MyStrategy` through
Freqtrade's `StrategyResolver` with the credential-free research configuration.
It exercised SMA240, EMA10, long/short entry conditions and disabled indicator
exits on synthetic candles. No orders or performance figures are generated by
this check. The existing CTA implementation changed only its introductory
disclosure text; its Python AST excluding that docstring is unchanged.

## Analysis checks

All 12 tests pass on host Python 3.10 and in the independent research container:

- Synthetic PnL, final equity, pair/side attribution and best-day removal reconcile.
- A first-day loss draws down from the initial capital peak.
- Zero-trade days are retained inside explicit date boundaries.
- Empty inputs, all wins, all losses and zero-return inputs produce valid JSON.
- Nonpositive equity disables annualized return ratios.
- Invalid capital, dates and profit values are rejected.
- Reading the synthetic SQLite fixture leaves its file hash unchanged.
- Missing database paths do not create empty databases.
- Schema errors omit input paths and raw SQLite exception details.
- CLI demo output identifies itself as synthetic and contains no per-trade export.
- SQLite synthetic fixtures can be explicitly labeled without misclassifying other inputs as live data.
- Existing output files are not overwritten.

Both Python AST parsing and shell syntax checks pass. The research Compose
configuration passes `docker compose config --quiet`. The credential-free research
configuration also passes Freqtrade backtest configuration/schema consistency
validation with MyStrategy resolved, without instantiating an exchange. Tests run with networking
disabled, a read-only repository/root filesystem and a temporary in-container
`/tmp` for generated fixtures.

## Publication review scope

The public repository's four visible historical commits and all 25 locally
available commit/blob/tag objects were scanned for common credential formats
and compared against known private configuration credential values. No matches
were found. The remote `main` matched the local baseline before migration.

All 43 public candidate files and the complete Git index were checked against
those private values, original
account-capital constants and private database paths without printing the
values. Only reviewed simulation aggregates, source, documentation and figures
were selected. No raw archive, account database, real trade table, runtime log,
private configuration or market data file was copied. `.gitignore` and a minimal
Docker build context protect common runtime artifacts. Pattern-based scanning
is scoped to reviewed files and locally available Git objects, not a guarantee
about every possible secret format.

Preparation and validation were completed before publication; existing Git
history was not rewritten and no credentials were changed.
Historical simulation results, CTA baseline results and synthetic demo output
are explicitly labeled separately in the documentation.
